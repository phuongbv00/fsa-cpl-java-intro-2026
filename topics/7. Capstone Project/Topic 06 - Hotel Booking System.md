# Topic 06: Hotel Booking System

## From: Elena Fisher (elena@azurebayresort.com)

## To: Dev Team

## Subject: Website for Azure Bay Resort

Hi Team,

I run Azure Bay Resort. We're a beautiful spot, but our booking process is ugly. We rely on Booking.com and they take 15% commission! I want more direct bookings.

I need a website that shows off our rooms—photos, amenities, prices. Guests should be able to put in their dates and see what's available. If they like it, they book it right there.

The backend needs to be robust. If someone books a room, it needs to instantly disappear from availability so we don't double-book. My front desk staff needs to see all bookings and check people in.

Since we get a lot of international tourists, having the site in English and Vietnamese (and maybe others later) would be a huge plus. Also, I'd love to have those cool 360-degree virtual tours of the rooms. Is that hard to embed?

One more thing—pricing. Can we make it so prices go up automatically during holidays?

Best,
Elena
