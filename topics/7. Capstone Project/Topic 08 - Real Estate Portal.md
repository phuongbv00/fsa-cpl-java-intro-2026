# Topic 08: Real Estate Portal

## From: Barbara Corcoran (barbara@homequest.realty)

## To: Dev Partners

## Subject: We need a better website

Hi there,

I run HomeQuest Realty. We have 30 agents selling houses and apartments all over the city.

Right now, if a client asks for a 2-bedroom apartment in District 2, my agents have to scroll through Zalo messages and Excel sheets to find options. It's unprofessional.

I want a centralized portal—like Batdongsan.com.vn—but just for our agency. Agents should be able to log in, upload photos of a house, set the price, and write a description. Buyers should be able to search—filter by price, location, bedrooms, etc.

If they like a house, they should be able to message the agent directly through the site.

In the future, I'd love to have a map search feature. You know, draw a circle on the map and see houses inside it? Also, a mortgage calculator would be nice for first-time buyers. And 3D tours! If we could support those, we'd blow the competition away.

Let's make this happen.

Barbara
