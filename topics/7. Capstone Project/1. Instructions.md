# Capstone Project Instructions

## 1. Overview

The Capstone Project is the final phase of the course, designed to consolidate your learning by building a complete software application.

- **Duration**: 8 weeks (4 Sprints).
- **Team Size**: 3-5 members per team.
- **Methodology**: Scrum/Agile.

## 2. Process & Timeline

The project will be executed in 4 Sprints (2 weeks per Sprint).

### Sprint 0: Inception (Week 1)

- **Activities**:
  - Team formation and Topic selection.
  - Requirement Analysis (User Stories, Use Cases).
  - Database Design (ERD).
  - Architecture Design (High-level architecture).
  - Setup Infrastructure (Git, CI/CD basic, Project Skeleton).
- **Deliverables**:
  - SRS Document (Software Legend Requirements Specification).
  - Design Documents (ERD, Class Diagram, Architecture Diagram).
  - Product Backlog on Project Management Tool (Jira/Trello/GitHub Projects).

### Sprint 1: Core Features (Week 2-3)

- **Focus**: Implement core functionality (Authentication, User Management, Main Business Logic basic flow).
- **Events**:
  - Sprint Planning.
  - Daily Standups.
  - Sprint Review (Demo).
  - Sprint Retrospective.

### Sprint 2: Advanced Features (Week 4-5)

- **Focus**: Expansion of business features, Reporting, Search/Filter optimization.
- **Events**: Standard Scrum events.

### Sprint 3: Finalization & Polish (Week 6-7)

- **Focus**: UI/UX improvements, validation, bug fixing, testing, deployment.
- **Events**: Standard Scrum events.

### Final Presentation (Week 8)

- Presentation and Demo of the final product.

## 3. Deliverables

All teams must submit:

1.  **Source Code**: Hosted on GitHub/GitLab with proper commit history.
2.  **Documentation**:
    - SRS (Software Requirements Specification).
    - SDD (Software Design Document).
    - API Documentation (Swagger/OpenAPI).
    - User Manual.
3.  **Deployed Application**: Link to the live application (e.g., Heroku, AWS, Render).
4.  **Presentation Slides**: For the final defense.

## 4. Evaluation Criteria

- **Functionality (40%)**: Completeness of features, logic correctness.
- **Technical Quality (30%)**: Code quality, architecture, database design, security, performance.
- **Process & Teamwork (20%)**: Adherence to Agile, Git usage, collaboration.
- **Documentation & Presentation (10%)**: Clarity of artifacts and final demo.
