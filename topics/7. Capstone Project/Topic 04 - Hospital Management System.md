# Topic 04: Hospital Management System

## From: Dr. Alan Grant (dr.grant@carefirst.net)

## To: Software Consultancy

## Subject: Digital Transformation for CareFirst

Good morning,

I'm the head doctor at CareFirst Clinic. We are a busy outpatient clinic, but our administration is stuck in the 1990s. We are still using paper files for patients!

It takes my receptionist 10 minutes to find a patient's file when they walk in. I want a system where we can type in a name and see everything—their history, allergies, past visits.

Booking is another issue. Patients call us, and the line is always busy. I want them to be able to book online. They should see which doctor is free and grab a slot.

For us doctors, we need to be able to see our schedule for the day and write prescriptions on the computer instead of handwriting them (my handwriting is terrible, pharmacists call me all the time to clarify).

Ideally, in the future, I'd love to offer video consultations for patients who can't come in. And maybe a tool that warns me if I prescribe a drug that interacts badly with what they're already taking? That would be a lifesaver. Oh, and a live waiting list on a TV screen so patients know when it's their turn?

Let me know if this is feasible.

Dr. Alan Grant
CareFirst Clinic
