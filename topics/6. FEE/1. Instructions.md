## **II. LEARNING ROADMAP & KNOWLEDGE SCOPE**

### **SESSION 1: WEB FUNDAMENTALS & UI BASICS**

**Goal:** Understand how the web works and build a semantic, responsive layout.

#### **1. Scope**

- **a) How the Web Works:**
  - Client (Browser) vs Server. Request/Response Cycle.
  - Browser Architecture: HTML Parser, DOM Tree, CSSOM, JS Engine (V8).
  - **Critical Rendering Path:** Render Tree -> Layout -> Paint.
  - Roles: HTML (Structure), CSS (Presentation), JS (Behavior).

- **b) HTML & Accessibility:**
  - **Structure:** `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`.
  - **Semantic Elements:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`. Why semantic?
  - **Accessibility (A11y):** ARIA roles overview, `alt` text, Keyboard navigation basics.
  - **SEO Basics:** Title, Meta tags, Heading hierarchy (`h1` -> `h6`).

- **c) CSS Fundamentals:**
  - **The Box Model:** Content, Padding, Border, Margin. `box-sizing: border-box`.
  - **Layout:** `display` (block, inline, inline-block), `position` (static, relative, absolute, fixed).
  - **Flexbox:** Container (`justify-content`, `align-items`) vs Item.
  - **Responsiveness:** Viewport meta tag, Media Queries (`@media`).
  - **Core Concepts:** Specificity (Calculation), Cascade, Inheritance.
  - **UI Frameworks:** Bootstrap/Tailwind (Introduction only, focus on Vanilla CSS first).

#### **2. Instruction: How to leverage AI/Web**

- **Browser:** "What happens when I type a URL into the browser and press Enter? Explain DNS, IP, and Rendering."
- **Semantic:** "Refactor this `div` soup HTML into Semantic HTML5."
- **Box Model:** "Explain the CSS Box Model. Why do developers use `* { box-sizing: border-box; }` reset?"
- **Flexbox:** "How to center a div both vertically and horizontally using Flexbox?"
- **Specificity:** "Calculate the specificity score of `div.container ul li` vs `#nav li`. Which one wins?"

### **SESSION 3: JAVASCRIPT & DOM MANIPULATION**

**Goal:** Add interactivity and communicate with Back-end APIs.

#### **1. Scope**

- **a) JavaScript Core:**
  - **Variables:** `let`, `const` (Block scope) vs `var` (Function scope).
  - **Types:** Primitive (String, Number, Boolean, Null, Undefined) vs Objects/Arrays.
  - **Functions:** Arrow Functions (`() => {}`) vs Declaration. Scope & Closures.
  - **Array Operations:** `.map()`, `.filter()`, `.reduce()`, `.find()` (Functional approach).
  - **Error Handling:** `try...catch`.

- **b) DOM Interaction:**
  - **DOM Tree:** `document.querySelector`, `document.getElementById`.
  - **Manipulation:** `innerHTML` vs `textContent`, `classList.add/remove`.
  - **Events:** `addEventListener`. Event Bubbling vs Capturing. Event Delegation pattern.
  - **Forms:** Handling `submit`, preventing default reload (`e.preventDefault()`).

- **c) Async & Networking:**
  - **Execution Model:** Event Loop, Call Stack, Callback Queue (Concept).
  - **Fetch API:** `fetch(url)`, Promises (`.then().catch()`), `async/await`.
  - **Structure:** Separation of Concerns (HTML in `.html`, CSS in `.css`, JS in `.js`). Folder structure.

#### **2. Instruction: How to leverage AI/Web**

- **ES6:** "What is the difference between `var`, `let`, and `const`? When to use which?"
- **DOM:** "What is the difference between `HTMLCollection` and `NodeList`?"
- **Events:** "Explain Event Delegation. Why is it better for list items than attaching listeners to each `li`?"
- **Async:** "Explain JavaScript Event Loop. How does `fetch` work without blocking the UI?"
- **Modules:** "How to use ES Modules (`import/export`) in the browser?"
