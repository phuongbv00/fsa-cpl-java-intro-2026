# **MINI LABS: QUICK PRACTICE EXERCISES**

Purpose: Small, isolated labs to help you verify the theories learned in the Instruction file.  
Requirement: Save screenshot or code snippet for your daily report.

---

### **SESSION 1 LABS: WEB FUNDAMENTALS**

**Lab 1.1 (Semantic HTML):**

- **Task:** Create a simple profile page `profile.html`.
- **Bad Practice:** Use only `div` and `span` tags.
- **Action:** Refactor it to use `<header>`, `<main>`, `<section>`, `<footer>`.
- **Verify:** Use Chrome DevTools > Elements to inspect the structure.

**Lab 1.2 (CSS Box Model & Flexbox):**

- **Task:** Create 3 boxes in a row.
- **Problem:** Add `padding: 20px` and `border: 5px solid red` to them. Notice they might break to the next line or grow unexpectedly.
- **Fix:** Apply `* { box-sizing: border-box; }` reset.
- **Flexbox:** Use `display: flex; justify-content: space-between;` on the container to space them evenly.
- **Responsive:** Use `@media (max-width: 600px)` to change `flex-direction` to `column` (stack them vertically on mobile).

### **SESSION 3 LABS: JS & DOM**

**Lab 3.1 (Variables & Scopes):**

- **Task:** Write a script inside `index.html`.
- **Experiment:**
  1. Declare `if (true) { var a = 1; let b = 2; }`.
  2. Try to console.log `a` and `b` outside the block.
  3. **Observation:** Which one causes ReferenceWarning? Why?

**Lab 3.2 (DOM Manipulation):**

- **Task:** Create a button `<button id="btn">Click Me</button>` and an empty `<ul>`.
- **Action:** Write JS to:
  1. Listen for 'click' on the button.
  2. Create a new `<li>Item</li>` element.
  3. Append it to the `<ul>`.
- **Verify:** Clicking adds items dynamically.

**Lab 3.3 (Fetch API):**

- **Task:** Fetch random user data.
- **Action:** Use `fetch('https://randomuser.me/api/')`.
- **Code:**
  ```javascript
  fetch("https://randomuser.me/api/")
    .then((response) => response.json())
    .then((data) => {
      console.log(data);
      // Bonus: Display the user's email on the page
    })
    .catch((error) => console.error(error));
  ```
- **Async/Await:** Rewrite the above using `async/await` syntax.
